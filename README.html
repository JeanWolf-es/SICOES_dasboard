¿Qué puedes hacer con esta aplicación?

Este panel de control de escritorio conecta directamente con los datos abiertos de contrataciones estatales de Bolivia (mauforonda/convocatorias_publicas) y los cruza con el mapa oficial de municipios para que puedas auditar procesos en segundos sin instalar bases de datos.

PASO 1

Abrir la aplicación y elegir el periodo de análisis

Para que el mapa de municipios cargue correctamente, abre la carpeta del proyecto usando un servidor local (por ejemplo, Live Server en VS Code o ejecutando python -m http.server 8080).

calendar_month Selector de Periodo

Por defecto carga los últimos 3 meses disponibles para darte velocidad inmediata. Puedes cambiar a un mes específico, un año completo o todo el histórico (2020–2022).

sync Botón Actualizar

Limpia la caché en memoria y vuelve a descargar los archivos CSV directamente desde GitHub Raw.

download Exportar CSV

Descarga en un archivo Excel/CSV únicamente los procesos que coinciden con tus filtros activos.

PASO 2

Usar la Barra Lateral de Filtros (Izquierda)

corporate_fare 1. Entidades Clave

Usa los botones rápidos para aislar al instante a instituciones estratégicas como ABC (Carreteras), BOA (Aviación), YPFB, Ministerios o el Sector Salud. Si buscas otra institución, usa el selector desplegable inferior ordenado por volumen de convocatorias.

account_tree 2. Nivel de Gobierno

Diferencia automáticamente entre el nivel Nacional (ministerios, empresas estratégicas, universidades), Departamental (Gobernaciones, SEDES) y Municipal (Alcaldías y Concejos).

map 3. Mapa Interactivo de Municipios de Bolivia

Haz clic en cualquier polígono municipal del mapa (por ejemplo, El Alto, La Paz, Cochabamba o Santa Cruz de la Sierra) o búscalo por nombre en el cuadro de texto superior. Todo el dashboard (tarjetas KPI, gráficos y tabla) se filtrará automáticamente para mostrar los procesos ejecutados por ese Gobierno Autónomo Municipal. Puedes usar el botón Ampliar para abrir el mapa en pantalla completa.

PASO 3

Analizar Gráficos y Explorar la Tabla de Convocatorias

  • bar_chart Top 10 Entidades: Muestra las instituciones con más convocatorias según tus filtros. Tip: Haz clic sobre cualquier barra del gráfico para filtrar la tabla por esa entidad.
  • pie_chart Distribución por Modalidad: Alterna entre vista de Pastel o Barras para comparar ANPE, Licitación Pública (LP), Contratación Directa (CD) y Contratación Menor (CM).
  • table_rows Tabla Interactiva y Ficha de Detalle: Busca en tiempo real por código CUCE, entidad u objeto del contrato, ordena por fecha o entidad, y haz clic en cualquier fila para abrir una ventana con todos los formularios, archivos y persona de contacto del proceso.
